## 2. Alcance

- Consultas sobre funciones habilitadas y configuracion de la cuenta.
- Recepcion y analisis de errores reproducibles, accesos y sincronizacion.
- Orientacion para usar las plantillas estandar de importacion.
- Canalizacion de incidentes de seguridad y solicitudes de salida de datos.

Incorporacion incluida y servicios adicionales: {{ALCANCE_INCORPORACION}}.
No se incluyen automaticamente desarrollos a medida, limpieza masiva de datos,
asesoria veterinaria/contable, reparacion de equipos o visitas presenciales.
Cualquier servicio adicional requiere presupuesto y aceptacion previa.

## 3. Clasificacion propuesta para aprobacion

| Prioridad | Ejemplo | Actuacion |
| --- | --- | --- |
| Critica | Sospecha de acceso entre clientes o perdida de datos | Escalar a seguridad, contener y conservar evidencia. |
| Alta | Operacion principal bloqueada sin alternativa | Diagnosticar impacto, alcance y alternativa temporal. |
| Normal | Error parcial con alternativa | Reproducir y programar correccion segun impacto. |
| Consulta | Uso, mejora o capacitacion | Orientar o evaluar propuesta; no prometer entrega. |

Esta clasificacion no fija un plazo de solucion. Una obligacion contractual de
disponibilidad, credito o recuperacion requiere acuerdo separado y capacidad medida.

## 4. Como reportar y proteger informacion

Indicar organizacion y finca, modulo, hora aproximada, pasos, mensaje de error y
version/navegador si se conoce. Las capturas deben ocultar datos personales ajenos.
No enviar contrasenas, tokens, claves R2, URI de base de datos ni datos de tarjeta.

El personal no debe pedir credenciales del cliente ni entrar a otra finca para
reproducir un error. Una intervencion en datos requiere autorizacion, aislamiento,
trazabilidad y respaldo cuando corresponda. No se enviara informacion de un cliente
a otro como ejemplo de soporte.

## 5. Mantenimiento y emergencias

Los mantenimientos previsibles se comunicaran por el canal acordado. Una incidencia
urgente puede exigir actuar antes del aviso; se informara segun el impacto y lo
legalmente procedente. No se asegura entrega instantanea de alertas o correos ni
que estos sustituyan la supervision de actividades ganaderas criticas.

El cierre de un caso debe indicar solucion o alternativa, comprobaciones realizadas
y limitaciones pendientes. Privacidad y reclamos se atienden por sus canales sin
exigir contratar un plan superior.
