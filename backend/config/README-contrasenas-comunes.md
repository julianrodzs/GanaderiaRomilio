# Catálogo de contraseñas comunes

`contrasenas-comunes-10000.txt` contiene las primeras 10.000 entradas de
`xato-net-10-million-passwords`, distribuida por el proyecto SecLists bajo su
licencia MIT.

Fuente consultada el 23 de octubre de 2026:
https://github.com/danielmiessler/SecLists/tree/master/Passwords/Common-Credentials

El archivo se incluye localmente para que la validación de contraseñas no
dependa de una red externa durante el registro, las invitaciones o la
recuperación de cuenta.
